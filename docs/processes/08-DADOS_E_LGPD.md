# Processo 08 — Dados e LGPD

## Objetivo
Tratar dados pessoais com base legal, minimizacao e rastreabilidade.

## Dono
- Founder

## Tipos de dados tratados
- identificacao: nome, e-mail, telefone
- profissionais: curriculo, historico de candidatura
- operacionais: logs de webhook e pagamento

## Regras operacionais
- coletar apenas o necessario para o fluxo
- limitar acesso por necessidade de funcao
- registrar finalidade do tratamento
- definir prazo de retencao

## Direitos do titular (fluxo interno)
1. Receber solicitacao
2. Confirmar identidade
3. Localizar dados no sistema
4. Executar acao (acesso/correcao/exclusao)
5. Responder dentro do prazo legal

## Checklist trimestral
- [ ] mapa de dados atualizado
- [ ] politicas de privacidade consistentes com produto
- [ ] processo de exclusao testado
- [ ] logs nao armazenam segredo em texto claro
