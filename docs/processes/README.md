# Manual de Processos — Recruta.AI

Objetivo: padronizar a operação da empresa (Founder + 1 dev), reduzir dependência de memória e criar rastreabilidade de decisões.

## Como usar

1. Cada processo tem:

- objetivo
- dono
- gatilho de execução
- entrada
- saída
- SLA
- checklist

2. Todo processo deve gerar evidência em um artefato simples:

- issue
- documento em `docs/`
- log de deploy
- planilha financeira

3. Cadência mínima de revisão:

- semanal: operação e produto
- mensal: segurança, financeiro e riscos
- trimestral: estratégia e posicionamento

## Critério de qualidade

Um processo só é considerado "vivo" quando:

- tem dono nomeado
- é executado com frequência definida
- produz evidência verificável
- teve pelo menos 1 melhoria em ciclo de 30 dias
